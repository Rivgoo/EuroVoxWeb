# EuroVox 2026 🎤

> Незалежна фанатська платформа для голосування за учасників **Гранд-фіналу Євробачення 2026**

![EuroVox](https://img.shields.io/badge/Eurovision-2026-orange?style=for-the-badge)
![React](https://img.shields.io/badge/React-18-blue?style=for-the-badge)
![TypeScript](https://img.shields.io/badge/TypeScript-5-blue?style=for-the-badge)
![Vite](https://img.shields.io/badge/Vite-6-purple?style=for-the-badge)

---

## Можливості

- 🎵 **25 учасників** Гранд-фіналу у порядку виступу
- ⭐ **4 критерії** оцінювання: Вокал, Шоу, Пісня, Загальне враження
- 🏆 **Результати** у реальному стилі Євробачення (рейтинг по балах)
- 💾 **Постійне збереження** — оцінки зберігаються у localStorage
- 📄 **Експорт у PDF** — повна таблиця результатів
- 🔍 **Пошук** учасників за країною, виконавцем або піснею
- 📱 **Mobile-first** — зручне голосування з телефону
- 🌈 **Eurovision-дизайн** — темна тема, помаранчевий акцент, веселка

## Встановлення у Visual Studio Code

### Крок 1 — Відкрийте термінал у VSCode

Натисніть **Ctrl+\`** (або **View → Terminal**).

### Крок 2 — Перейдіть до папки проєкту

```bash
# Якщо ви розпакували архів, наприклад, у ~/Downloads/eurovox
cd ~/Downloads/eurovox

# Або для Windows
cd C:\Users\ВашеІм'я\Downloads\eurovox
```

### Крок 3 — Встановіть залежності

```bash
npm install
```

Це займе 1–2 хвилини. Буде завантажено React, TypeScript, Vite, іконки Tabler та бібліотеки PDF.

### Крок 4 — Запустіть сайт

```bash
npm run dev
```

Відкрийте браузер та перейдіть за посиланням, яке з'явиться у терміналі (зазвичай **http://localhost:5173**).

## Як користуватися

### Оцінювання (вкладка «Учасники»)
1. Натисніть на картку будь-якої країни
2. У модальному вікні оберіть оцінки від 1 до 10 за 4 критеріями
3. Натисніть повторно на кнопку з оцінкою, щоб скасувати її
4. Посилання на YouTube — внизу модального вікна
5. Закрийте вікно (×, Escape або клік поза межами)

### Результати (вкладка «Результати»)
- Країни відсортовані за загальним балом (макс. 40 очок)
- Топ-3 відзначено медалями 🥇🥈🥉
- Натисніть на будь-яку країну, щоб змінити оцінки
- Кнопка **PDF** — зберегти результати як файл

### Очищення оцінок
- Натисніть значок 🗑️ у правому верхньому куті
- Підтвердіть очищення у діалозі

## Збереження даних

Всі оцінки зберігаються у **localStorage** браузера під ключем `eurovox_votes_2026`. Вони не видаляються після закриття вкладки чи браузера. Очистити можна лише вручну через кнопку скидання.
